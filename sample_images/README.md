# sample_images/

No real photos of people are bundled with this repo, on purpose -- running
face recognition on someone's photo without their consent is exactly the
kind of thing this project's own disclaimer asks you not to do.

`synthetic_test_face.jpg` **is** bundled, so you can try the pipeline
immediately with zero setup. It's AI-generated by
https://thispersondoesnotexist.com and depicts no real person:

```
python main.py sample_images/synthetic_test_face.jpg --mock-search
```

To try it with your own (consented) photo instead, drop it in here, e.g.
`sample_images/me.jpg`, and point the command at that file instead.

Once you have a `GOOGLE_VISION_API_KEY` set in `.env`, drop `--mock-search`
to run a genuine reverse-image search. (A search on the synthetic face
likely won't find a social media match, since it doesn't correspond to any
real online presence -- use a real, consented photo to see a genuine match.)
